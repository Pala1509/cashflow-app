# CashFlow — Tu control financiero.

App de finanzas personales de Vanta Lab Studio. React + Vite + Tailwind v4 + Supabase, empacada con Capacitor para Android (y luego iOS).

## 1. Base de datos (Supabase)
1. Abre tu proyecto en supabase.com → SQL Editor → New query.
2. Pega y ejecuta `supabase/schema_cashflow.sql` completo.
3. Si quieres OTP por celular: Authentication → Providers → Phone → activa un proveedor (Twilio es el más común).

## 2. Variables de entorno
```
cp .env.example .env.local
```
Y pon ahí tu `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY` (Settings → API en Supabase).

## 3. Correr en el navegador
```
npm install
npm run dev
```

## Logos
Los 3 logos oficiales viven en `src/assets/logos/`:
- `logo-oficial.png` — lima sobre negro. Es el que usa la app (login, ícono, splash).
- `logo-lima-transparente.png` — CF en lima, fondo transparente.
- `logo-blanco-transparente.png` — CF en blanco, fondo transparente.

El ícono de la app y la pantalla de carga nativa de Android ya están generados (carpeta `android/app/src/main/res/`) a partir de `resources/icon.png` y `resources/splash.png`. Si cambias el logo, solo actualiza esos dos archivos en `resources/` y corre:
```
npx capacitor-assets generate --android
```

## 4. Empacar para Android (¡ya está listo!)
La carpeta `android/` ya viene generada en este zip. Solo te falta:
```
npm install
npm run build
npx cap sync android
npx cap open android      # abre Android Studio
```
Una vez abierto en Android Studio:
1. Conecta tu tablet por USB.
2. En tu tablet: Ajustes → Acerca de la tablet → toca 7 veces "Número de compilación" para activar Opciones de desarrollador.
3. Ajustes → Opciones de desarrollador → activa "Depuración por USB".
4. En Android Studio, tu tablet debería aparecer en la lista de dispositivos (arriba, junto al botón ▶️ Run).
5. Selecciónala y dale ▶️ Run — la app se instala y abre sola en tu tablet.

Cada vez que hagamos cambios en el código: `npm run build && npx cap sync android`, y vuelve a darle Run en Android Studio (no hace falta repetir `cap add`).

Cuando quieras el APK instalable sin cable (para compartirlo): Build → Build Bundle(s)/APK(s) → Build APK(s) en Android Studio, y el archivo queda en `android/app/build/outputs/apk/`.

## Decisión de arquitectura: datos
Todos los datos (Free y Pro) viven en Supabase, nunca solo local. La diferencia
entre planes está 100% en las funciones desbloqueadas (ver `src/lib/pro.ts` y
`ProPaywallSheet`), no en dónde se guarda la información. Esto es intencional:
así todos los usuarios tienen sus datos sincronizados entre celular/tablet desde
el primer día, sin riesgo de perder su historial financiero por borrar caché o
cambiar de dispositivo.

## Responsive: 3 niveles
- **Celular (< 768px):** tab bar inferior, una sola columna. Sin cambios.
- **Tablet vertical (768–1023px):** aparece el rail lateral, pero el contenido se queda en una sola columna (no hay ancho cómodo para dos paneles).
- **Tablet horizontal / PC (≥ 1024px):** rail lateral + contenido en 2 columnas (o grilla de 3 en Presupuestos), con ancho máximo de 900px centrado para no estirarse en pantallas muy anchas.
